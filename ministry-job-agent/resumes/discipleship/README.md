# Resume — discipleship

Place your resume for this variant here:

- `resume.md` — the working version
- `resume-ats.txt` — plain text, ATS-friendly

**The agent does not write resume content.** Until `resume.md` exists, this
variant is NOT_PROVIDED, and any application package that selects it is blocked
from approval.

Tailoring may reorder bullets, change emphasis, adjust the summary, select
relevant accomplishments, and work in job-specific keywords naturally.

Tailoring may never invent accomplishments, inflate metrics, change dates, alter
titles, create responsibilities you did not perform, or fabricate ministry growth.

Files here are gitignored.
