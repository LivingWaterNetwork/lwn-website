# Portfolio — living-water-network

Place the summary, links, and selected excerpts for this asset here.

Recommended: a one-page `summary.md` that can be linked or attached, plus any
excerpts you are willing to share.

**Do not put full curricula here for automatic attachment.** Applications get a
summary and a link, never a document dump — an application buried in attachments
reads as a mass mailing.

Scale claims (participants, churches reached, budget, organizational or tax
status) are candidate facts, not portfolio copy. They belong in the candidate
database once you approve them, and the system will never infer them.

Files here are gitignored.
