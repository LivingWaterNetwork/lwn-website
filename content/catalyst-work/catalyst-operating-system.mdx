summary: A three-layer architecture for how mission-driven organizations run — a neutral core of shared systems, an organization layer that carries identity and governance, and a deployment layer where the public-facing work lives.
challenge: >-
  Organizations that grow past their founder usually hit the same wall. The knowledge lives
  in people's heads, each new initiative reinvents its own systems, and the tools multiply
  faster than anyone can document them. What's missing is rarely effort or vision — it's a
  shared structure that lets a new initiative inherit what already works instead of starting
  from nothing.
approach: >-
  The operating system separates concerns into three layers. The neutral core holds the parts
  that shouldn't be rebuilt per initiative — shared conventions, data handling, validation,
  notification, and design foundations. The organization layer carries what makes a given
  organization itself: identity, mission language, governance, and the decisions that
  shouldn't drift. The deployment layer is where a specific site, program, or initiative
  actually ships, drawing on both layers beneath it.
workCompleted:
  - Three-layer architecture defined and documented
  - Neutral core patterns proven in production across multiple initiatives on one platform
  - Shared conventions for validation, persistence, notification, and design established in real use
  - Initiative-launch pattern demonstrated end to end

This is an architecture in progress, not a product. What exists today is a working pattern
observed across the initiatives already built on one platform, and the ongoing work of making
that pattern explicit enough to reuse deliberately.
