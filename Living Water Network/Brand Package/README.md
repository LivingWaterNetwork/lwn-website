# Living Water Network — Brand Package v1.0

A complete, refined visual identity built on your original globe-and-living-water concept — elevated into a clean, scalable, print-ready system.

## Start here
- **`guidelines/Living-Water-Network-Brand-Guidelines.html`** — the full brand book. Open in any browser. To save as PDF: open it, then File → Print → Save as PDF.

## Logos (`logos/`)
Every logo comes as **SVG** (infinitely scalable, for designers/print) and **PNG** (high-resolution, for everyday use).

| File | Use it for |
|------|-----------|
| `LWN-logo-primary-light` | Main logo on white / light backgrounds |
| `LWN-logo-primary-dark` | Main logo on navy / dark / photo backgrounds |
| `LWN-logo-horizontal-light` / `-dark` | Website headers, email signatures, letterhead |
| `LWN-icon` | Standalone globe mark (app icon, stamp) |
| `LWN-icon-on-navy` | Social avatar (square, navy background) |
| `LWN-logo-mono-navy` / `-white` / `-black` | Single-color uses (engraving, fax, one-ink print) |
| `png/favicon-16…512` | Website favicon / app icons |
| `png/avatar-1024` | Profile picture for all social platforms |

## Colors (quick reference)
- Deep Ocean `#07273B` · Living Water Blue `#1E9BD7` · Bright Aqua `#36C5E0`
- Living Gold `#ED9F3C` (accent only) · Abyssal Teal `#0A5E83`
- Full RGB / CMYK values are in the brand book.

## Fonts (all free — Google Fonts)
- **Poppins** — wordmark & headlines
- **Lora** — scripture & reflective quotes
- **Lato** — body text
